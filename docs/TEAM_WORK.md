# Team Work Distribution

Suggested division for a 4-member group:

## Member 1 - Data Preparation
- Prepare employee spreadsheet/CSV.
- Check column names and sample records.
- Validate data before import.

## Member 2 - Import Set
- Create the Import Set.
- Upload the CSV.
- Verify that source rows are loaded.

## Member 3 - Transform Map
- Create the Transform Map.
- Configure source-to-target field mappings.
- Configure a unique/coalesce field when required.

## Member 4 - Testing & Documentation
- Run the transform.
- Verify target records.
- Check errors/ignored rows.
- Capture screenshots and prepare the final documentation.

## Important
The team does not need to repeat the same ServiceNow configuration four times. Each member can own a part of the workflow, while all members should understand the complete flow for the final demonstration.
